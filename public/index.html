What each metric means

DEAD STOCK
SKUs onboarded with ZERO usage in any PKO across Apr 2025 – May 2026.
DEAD VALUE
Catalog selling value of dead SKUs (BNG SP or MUM SP). Not procurement cost.
OLD DEAD (>1 yr)
Dead SKUs in Studio for over 12 months. Most actionable for delisting.
SLOW MOVERS
SKUs used in 1 to 5 PKO projects in LAST 6 MONTHS. At risk of turning dead.
DISCONTINUED
PKO sales billed against ERP codes no longer in Studio. Mostly service line items already collected.

per PKO (₹ L)
How shares are calculated: for each PKO, we count the number of line items per Main category (Modular / Neo Modular / Studio / Service), then divide by that PKO's total line items.
Example: a project with 80 Modular line items + 10 Studio + 5 Neo Modular + 5 Service = 100 total → Modular 80%, Studio 10%, Neo 5%, Service 5%. We use item count (not revenue) so a small number of expensive items doesn't skew the picture. Project Value is shown only as project size context.
